# Prompt Glossary

A research-backed reference library of visual vocabulary for AI image and video generation. Each page covers a dimension of visual creation — the real-world concepts, what they look like, and how they interact.

## Purpose

Know the vocabulary, understand the effects, compose prompts by inference — not by guessing.

## Format

Each entry follows this structure:

- **Term** — the canonical phrasing
- **What it is** — real-world definition with context
- **Visual effect** — what it does to the image when used in a prompt
- **Pairs well with** — complementary terms from any category
- **Conflicts with** — terms that fight or cancel the effect
