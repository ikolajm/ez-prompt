# Composition Matrix

The entire glossary compressed into one scannable reference. Each row is a use case. Each column is a prompt dimension. Each cell contains the 2-3 strongest terms for that combination.

Pick one term per column. Assemble. You have a prompt.

## How to Use This Matrix

1. Find your use case row
2. Pick one term from each column
3. Assemble in prompt skeleton order: Subject + Style + Camera + Lighting + Color + Composition + Atmosphere + Mood
4. If the output isn't right, swap one term — don't add more terms
5. For deeper understanding of any term, go to the full vocabulary page

This matrix is a starting point, not a limit. Every cell links back to a glossary page with 10-30 options per dimension. The matrix shows the defaults — the glossary has the full menu.
