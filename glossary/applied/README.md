# Applied Compositions

Recipes for specific real-world outputs. Each entry combines terms from the [vocabulary glossary](../README.md) into composable prompt formulas for common creative briefs.

## How to Use

The vocabulary pages tell you *what* each term does. These pages tell you *when* and *how* to combine them. Each recipe is a starting point — swap any term for another from the same glossary category to shift the result.

## Recipe Format

Each entry follows this structure:

- **The brief** — what the creator needs (the real-world deliverable)
- **The recipe** — specific glossary terms for camera, lighting, angle, color, style
- **Example prompt** — a composable string you can use directly
- **Variations** — swap terms to shift the result
- **Common mistakes** — conflicting terms, overloaded prompts
